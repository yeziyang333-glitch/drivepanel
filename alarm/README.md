# 連環鬧鐘（tw.chainalarm）

一次排好一整串鬧鐘的 Android App：設定第一個、最後一個時間與間隔（例如 07:10 → 08:30 每 10 分鐘），不用一個一個建。

- **單次**：例如 11/21 考試
- **上班日**：跟著台灣行政機關辦公日曆，國定假日、連假自動不響，補班的週六會響
- **自選星期**：可選國定假日不響
- **請假日期**：當天上班鬧鐘跳過（單次鬧鐘照響）
- **鈴聲**：系統鬧鐘鈴聲或手機裡的音樂檔；可音量漸強
- 響鈴時可按「停止」只關這一個，或「起來了，今天這組剩下的不響」

下載：[`apk/ChainAlarm-latest.apk`](apk/ChainAlarm-latest.apk)

辦公日曆資料來源：政府資料開放平臺「中華民國政府行政機關辦公日曆表」，經 [ruyut/TaiwanCalendar](https://github.com/ruyut/TaiwanCalendar) 整理。
